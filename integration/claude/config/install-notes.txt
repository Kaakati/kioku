Kioku host package -- installation notes
=======================================

Three entry points, one implementation package. None of them boots Rails.

  bin/contextctl     hook dispatch + operator commands (doctor, status, spool, pair)
  bin/context-agent  persistent host service: filesystem authority, spool, bridge
  bin/context-mcp    MCP stdio server exposing the six context_* tools

Supported hosts are Linux/WSL and macOS. The private Unix socket stays on the
host and is never mounted through Docker Desktop.

1. Dependencies
---------------
    cd integration/claude && bundle install

  mcp 1.5.1 is the official Ruby MCP SDK. base64 is pinned explicitly because
  Ruby 3.4 demoted it from a default gem and mcp 1.5.1 omits it from its
  gemspec. The dependency chain reaches bigdecimal, which is native, so the
  host needs either a compiler at install time or prebuilt platform gems.

2. Pair the installation
------------------------
    bin/contextctl pair --token "$KIOKU_BRIDGE_TOKEN" \
                        --api-url http://127.0.0.1:7310 \
                        --project my-project=/home/me/code/my-project

  This writes ~/.kioku/config.json with mode 0600. --project binds a registered
  project key to an approved root. A root with no binding stays unresolved: it
  is never attached to another project's history and never reinterpreted as a
  global capture.

3. Start the agent
------------------
    bin/context-agent run

  Run it under the operator's own service manager (systemd --user, launchd).
  It creates ~/.kioku/run/agent.sock with mode 0600, opens the authenticated
  loopback control connection to the core, and drains the durable spool every
  15 seconds.

4. Register with Claude Code
----------------------------
  Merge config/hooks.json into the settings file and config/mcp.json into the
  MCP configuration, dropping the "$comment" keys. Read the comments in both
  files first: the hook timeouts now contain Ruby interpreter startup, and the
  hook events do not share one output contract.

5. Verify
---------
    bin/contextctl doctor

  Checks Ruby, the mcp gem, the Claude client and its registration, approved
  roots, the host socket and agent, the durable spool, the authenticated core,
  the PostgreSQL/ParadeDB state the core reports, and Docker reachability.
  Exit status is 1 if any check fails.

Environment
-----------
  KIOKU_HOME              default ~/.kioku (durable data; never a plugin dir)
  KIOKU_SOCKET_PATH       default $KIOKU_HOME/run/agent.sock
  KIOKU_API_URL           default http://127.0.0.1:7310
  KIOKU_BRIDGE_TOKEN      bridge credential; the agent alone holds it
  KIOKU_OBJECT_ROOT       default $KIOKU_HOME/objects
  KIOKU_SPOOL_DIR         default $KIOKU_HOME/spool
  KIOKU_SPOOL_MAX_BYTES   default 67108864
  KIOKU_APPROVED_ROOTS    PATH-separated list, overrides the config file
  KIOKU_HOOK_DEADLINE_MS  default 700, inside the 1s hook timeout
  KIOKU_LOG_LEVEL         debug|info|warn|error, default warn

Degradation
-----------
  Core down          hooks return without enhancement; eligible capture is
                     spooled; reads fail visibly; writes answer queued.
  Agent down         hooks return without enhancement and record nothing;
                     context-mcp spools mutations itself and answers queued.
  Spool full         kioku.quota_exhausted. Unacknowledged durable records are
                     never discarded to make room.

  queued means durably enqueued on this host. Only a canonical receipt from the
  core means saved. Nothing in this package can produce a saved result.

Tests
-----
    ruby -Ilib -Itest test/run_all.rb
